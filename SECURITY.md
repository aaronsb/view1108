# Security Policy

VIEW-1108 is a static web page (FORTRAN compiled to WebAssembly) served from GitHub Pages, plus a local build toolchain. It has no server, accounts or user data.

## Supported versions

Only the current `main` branch, and the page built from it at https://aaronsb.github.io/view1108/, is supported.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Contact the repository owner, [@aaronsb](https://github.com/aaronsb), privately through GitHub, with a description, the steps to reproduce, and the affected file or page.

You can expect an acknowledgement within a week. Non-sensitive problems (a broken build, a page bug) can go in a normal issue.
